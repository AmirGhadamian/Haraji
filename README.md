# بازار من — سایت آگهی و حراجی (Django)

یک وب‌اپلیکیشن جنگویی با دو بخش:
1. **آگهی**: کاربران می‌توانند محصول خود را با قیمت مشخص ثبت کنند.
2. **حراجی**: فروشنده می‌تواند هر آگهی خودش را وارد حراجی کند؛ کاربران دیگر روی آن پیشنهاد قیمت می‌دهند و در پایان زمان تعیین‌شده، بالاترین پیشنهاد برنده می‌شود.

## اجرای پروژه

```bash
# ۱. ساخت محیط مجازی (اختیاری ولی توصیه‌شده)
python -m venv venv
source venv/bin/activate     # ویندوز: venv\Scripts\activate

# ۲. نصب پیش‌نیازها
pip install -r requirements.txt

# ۳. ساخت دیتابیس
python manage.py migrate

# ۴. ساخت حساب مدیر (برای دسترسی به /admin/)
python manage.py createsuperuser

# ۵. اجرای سرور
python manage.py runserver
```

سپس آدرس http://127.0.0.1:8000 را در مرورگر باز کنید.

## ساختار پروژه

```
bazar_site/       تنظیمات اصلی جنگو (settings, urls)
market/           اپ اصلی: مدل‌ها، ویوها، فرم‌ها، ادمین
templates/        قالب‌های HTML (RTL، بوت‌استرپ ۵، فونت وزیرمتن)
media/            تصاویر آپلودشده‌ی آگهی‌ها (بعد از اجرا ساخته می‌شود)
```

## مدل‌های اصلی (market/models.py)

- **Category**: دسته‌بندی آگهی‌ها
- **Listing**: آگهی — عنوان، توضیحات، قیمت، تصویر، فروشنده، وضعیت (عادی / در حراجی / فروخته‌شده)
- **Auction**: حراجی مرتبط با یک آگهی — قیمت پایه، حداقل افزایش قیمت، زمان پایان، برنده
- **Bid**: پیشنهاد قیمت هر کاربر روی یک حراجی

## منطق حراجی

- فقط صاحب آگهی می‌تواند آن را وارد حراجی کند (`start_auction`).
- کاربران دیگر (به‌جز فروشنده) می‌توانند در حراجی پیشنهاد بدهند؛ هر پیشنهاد باید حداقل به‌اندازه‌ی «حداقل افزایش قیمت» از بالاترین پیشنهاد فعلی بیشتر باشد.
- هنگام بازدید از صفحات آگهی/حراجی، سیستم به‌صورت خودکار بررسی می‌کند که آیا زمان حراجی تمام شده یا نه (`close_if_needed`). اگر تمام شده باشد، حراجی بسته و بالاترین پیشنهاددهنده به‌عنوان برنده ثبت می‌شود و وضعیت آگهی به «فروخته‌شده» تغییر می‌کند.
- برای پروژه‌ی واقعی، بهتر است این بستن خودکار را با یک **Celery beat task** یا **cron job** / `django-crontab` هر چند دقیقه اجرا کنید تا حتی بدون بازدید کاربر هم حراجی‌ها به‌موقع بسته شوند. نمونه‌ی فعلی این کار را در لحظه‌ی بازدید از صفحه انجام می‌دهد که برای دمو کافی است.

## نکات برای تبدیل به پروژه‌ی واقعی (Production)

قبل از انتشار روی هاست واقعی حتماً موارد زیر را انجام دهید:

1. `DEBUG = False` و `ALLOWED_HOSTS` را به دامنه‌ی واقعی محدود کنید (الان `['*']` است که فقط برای توسعه مناسب است).
2. `SECRET_KEY` را در فایل `.env` جدا نگه دارید و مقدار تصادفی و جدید تولید کنید.
3. از SQLite به PostgreSQL یا MySQL مهاجرت کنید.
4. برای آپلود تصاویر در سرور واقعی از یک storage مثل S3 استفاده کنید.
5. یک وب‌سرور production (gunicorn/uwsgi + nginx) به‌جای `runserver` استفاده کنید.
6. HTTPS و تنظیمات امنیتی جنگو (`SECURE_*`, `CSRF_COOKIE_SECURE`, ...) را فعال کنید.
7. برای بستن خودکار حراجی‌ها، یک وظیفه‌ی زمان‌بندی‌شده (cron/Celery) اضافه کنید.

## امکانات فعلی

- ثبت‌نام / ورود / خروج کاربر
- ثبت آگهی جدید با تصویر و دسته‌بندی
- تبدیل آگهی به حراجی توسط فروشنده
- شرکت در حراجی و ثبت پیشنهاد قیمت با اعتبارسنجی حداقل مبلغ
- نمایش تاریخچه‌ی پیشنهادها
- تعیین خودکار برنده در پایان زمان حراجی
- پنل «حساب من»: آگهی‌های من، پیشنهادهای من، حراجی‌هایی که برنده شده‌ام
- پنل مدیریت جنگو برای مدیریت کامل داده‌ها (`/admin/`)
- طراحی راست‌به‌چپ (RTL) با بوت‌استرپ ۵ و فونت فارسی وزیرمتن
